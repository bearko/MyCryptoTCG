# テストケース総覧

このテンプレートでカバーすべき汎用テストケース。 各プロジェクトでは「該当する項目」 をチェックリストとして使う。

## 1. 起動 / ロード

- [ ] index.html を開いて Console エラーがない
- [ ] localStorage が空の状態で初回起動できる
- [ ] localStorage に古い save data が残っていてもクラッシュしない
- [ ] JSON ロードが失敗した場合のフォールバック (= 「データが読めません」 表示)
- [ ] 画像 / 音声 ロード失敗時にプレースホルダで進む (= 真っ白にならない)

## 2. レイアウト / 動作環境

### 2.1 PC

- [ ] 1280×800 で全 view が表示される
- [ ] 1920×1080 で間延びせず中央に集まる (= max-width 制御)
- [ ] 横スクロールが発生しない
- [ ] 縦スクロール不要な画面で縦スクロール出ない

### 2.2 Tablet

- [ ] iPad (768×1024) でレイアウトが崩れない
- [ ] 横向きでも UI が破綻しない

### 2.3 Mobile

- [ ] iPhone SE (375×667) で UI が破綻しない
- [ ] 縦スクロールがある画面でフッタを覆い隠さない
- [ ] safe-area (= iPhone X 系のノッチ) 考慮済み
- [ ] viewport meta tag が `viewport-fit=cover` を含む
- [ ] テキストが画面外にはみ出さない (= ellipsis / wrap 動作)
- [ ] ボタンが押しやすい (= 44px 以上のタップ領域)

## 3. 多言語 (i18n)

- [ ] 起動時に localStorage の言語が復元される
- [ ] JP/EN トグルで全文字列が即座に切り替わる
- [ ] 未翻訳キーで fallback 表示 (= 日本語 or キー名)
- [ ] `{var}` 置換が正しく動く
- [ ] data-i18n-attr-placeholder が input 要素に効く
- [ ] data-i18n-html が innerHTML に効く
- [ ] ヘルプオーバーレイ内のテキストが切り替わる
- [ ] modal 開閉中に言語切替しても表示が崩れない
- [ ] ヒーロー名 / アイテム名が EN に切り替わる
- [ ] runtime 動的テキスト (= "10 ダメージ") が翻訳される

## 4. ヘルプオーバーレイ

- [ ] ヘルプボタンで開く
- [ ] 閉じるボタンで閉じる
- [ ] 背景クリックで閉じる
- [ ] Esc キーで閉じる
- [ ] 表示中は時間が停止する
- [ ] 閉じると時間が再開する
- [ ] body の overflow:hidden が外れる

## 5. レイヤー (z-index)

- [ ] modal が常に通常 UI より上
- [ ] cut-in が modal より上
- [ ] 紙吹雪が modal の上に降る (= ✗ こだわりがある場合 modal の下)
- [ ] 通知タイルが他 UI を邪魔しない
- [ ] splash screen が全要素より上
- [ ] ranking modal が他 modal より上

## 6. 音響

- [ ] BGM がタイトル dismiss 後に開始される (= autoplay 制限回避)
- [ ] BGM が view 切替で適切に切り替わる
- [ ] SE 連打で音が重ならない (= throttle 効いてる)
- [ ] 音声ファイルロード失敗で他処理が止まらない
- [ ] ミュートトグル (= ある場合) で BGM/SE が切れる

## 7. エフェクト

- [ ] 紙吹雪が一定時間で消える
- [ ] sprite float (= +N) が浮上して消える
- [ ] shake animation がリトリガできる (= reflow 強制)
- [ ] popup 数値が他 UI と重ならない
- [ ] prefers-reduced-motion ON 時にアニメ停止

## 8. UI コンポーネント

### 8.1 ボタン

- [ ] hover でフィードバック
- [ ] active (= mousedown) で押し込み感
- [ ] disabled で opacity 下がる + cursor:not-allowed
- [ ] mobile タップで反応 (= :active を使うと iOS で効かない場合あり)

### 8.2 Modal

- [ ] 表示中は時間停止
- [ ] 閉じると時間再開
- [ ] 連続開閉して pauseFlags が 0 に戻る
- [ ] 3 つの閉じ方 (= 閉じるボタン / 背景クリック / Esc) すべて動く
- [ ] modal 内の scroll が body に伝播しない
- [ ] 表示中に語切替で文字列が更新される

### 8.3 通知タイル

- [ ] 一定時間で消える
- [ ] 連続発火で複数表示できる (= 3 個まで等の上限)
- [ ] スライドイン animation
- [ ] 旧通知が積み残らない (= TTL 過ぎたら消える)

## 9. 時間制御

- [ ] 通常速度で 1 tick = 1 sec
- [ ] 2x で 1 tick = 0.5 sec
- [ ] 20x で 1 tick = 0.05 sec
- [ ] modal 開いている間 tick が進まない
- [ ] 連続イベント発火で freeze しない
- [ ] 速度変更が即時反映される (= setInterval 再起動)

## 10. State / セーブ (= 実装した場合)

- [ ] save → reload で完全復元
- [ ] save 中にクラッシュしても data 破損しない
- [ ] 古い version の save が新コードで読める (= migration)
- [ ] localStorage 容量超過時のエラーハンドリング

## 11. ランキング (= GAS 統合する場合)

- [ ] localStorage に URL を保存 → 別ブラウザで開いて反映されるか
- [ ] 既定 URL のみで送信できるか (= localStorage 空)
- [ ] 送信失敗時に「ランキング API URL が未設定」 が表示される
- [ ] 上位 50 件が score 降順で並ぶ
- [ ] version フィルタが効く
- [ ] 同じプレイヤーが複数回送ったとき、 すべて記録される
- [ ] 30 文字超のプレイヤー名が trim される
- [ ] 1〜3 位がハイライトされる (= 金/銀/銅)
- [ ] 通信エラー時にローディング表示が消える

## 12. 並列スロット (= 採用した場合)

- [ ] Lv 1 で 1 スロットのみ動く
- [ ] Lv 2 で 2 スロット同時に動く
- [ ] Lv 3 で 3 スロット同時に動く
- [ ] 全スロットが埋まっている時に新規開始ができない
- [ ] スロットページャ (= ▶ / ◀) で表示切替できる
- [ ] 1 スロットだけ完了して他は継続中、 が動く
- [ ] state.activeXxx (= slot 0) と state.activeXxxExtra (= slot 1+) の互換性

## 13. 月次イベント

- [ ] 1 月 4 週: 給与事前警告 (= 初年度はスキップ)
- [ ] 4 月 1 週: 年俸支払い (= 初年度は subsidy)
- [ ] 5 月 1 週: 採用イベント
- [ ] 5 月 3 週: 行商人 (= 採用済みなら別イベント)
- [ ] 12 月 1 週: コンテスト (= 1 年目はスキップ)
- [ ] 同じ年内で同じイベントが重複発火しない (= dedup Set)
- [ ] 連続イベントで freeze しない

## 14. 規約遵守

- [ ] Conventional Commits が守られている
- [ ] PR template に記入済み
- [ ] CLAUDE.md の命名規則に従っている
- [ ] 新規ファイルが該当ディレクトリ (= js/, css/, data/) に置かれている
- [ ] 不要な console.log / TODO が残っていない
- [ ] ファイル末尾に改行がある

## 15. リリース前最終チェック

- [ ] main → prod merge を ff-only でできるか
- [ ] Vercel preview と本番で挙動が一致するか
- [ ] 旧 save data がそのまま読めるか (= breaking change がある場合は明示)
- [ ] CHANGELOG / Release Notes 書いた
- [ ] tag を打った
- [ ] 関係者へのアナウンス
