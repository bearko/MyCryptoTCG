# SPEC-112 — UI の作り込みと分かりやすさ

SPEC-111 で「遊び切れる」スマホ UI はできた。ここでは **完成度** と **分かりやすさ** を上げる。
目標は、UI の作り込みで評価の高い参考作と並べても見劣りしないこと。
エンジン（`js/engine/*`）とルールは変えない。**UI はエンジンに聞くだけ**（SPEC-111 §10）。

## 0. 4 つの原則

| 原則 | 意味 | このゲームでの形 |
|---|---|---|
| **A. 期待を超えるリアクション** | 触ると必ず何かが返ってくる。同じ画面でも毎回少し違う | ヒーローの立ち位置・向きの差分、吹き出しが文字数に合わせて伸びる、数値が転がる、押した場所から波紋 |
| **B. 世界観をまとった質感** | 画面が「板」ではなく「手に持ったガジェット」に見える | 端末の縁のハイライト、パネルのエッジ光、ガラスの奥行き、文字の裏にキャラ・手前にもキャラ（レイヤーの重なり） |
| **C. 心地よいアニメーション** | 情報を取りに行く操作ほど、短く気持ちよく動く | アプリはアイコンの位置から開く、会話は 500〜700ms でめくれる、経路は線が伸びる、陥落はカットイン |
| **D. 止まらない画面と色の優先度** | どの画面でも何かが微かに動いている。UI は背景より彩度が高い | 壁紙のゆっくりした移動・粒子・時計の秒、マップは UI の下で一段暗く彩度を落とす |

加えて **E. 迷わせない**: 次に何をすればよいかを、いつも 1 つ示す。

## 1. 共通の基盤（`css/theme.css`・`js/ui/fx.js` 新規・`js/ui/h.js`）

- **トークン**: 色（背景 3 段・パネル 3 段・アクセント金・ランド色・状態色）、角丸、影、時間（`--t-tap 120ms` `--t-ui 240ms` `--t-page 600ms`）、イージング（`--ease-out` `--ease-spring`）
- **端末の質感**: `.phone` に縁のハイライト（上辺が明るく下辺が暗いグラデーションの 1px）、内側の微かな影、画面のガラス反射（斜めの薄い光）。880px 以上では端末を机に置いたように見せる（周りに影）
- **パネル**: `.panel` に上辺のエッジ光（1px の明るい線）＋下辺の暗線＋背景の薄いノイズ。押せるパネルは押すと 2px 沈む
- **ボタン**: 押した場所から波紋（`fx.ripple`）、押下で縮む（scale .96）、主要ボタンは光が横切る（数秒に 1 回）
- **数値**: 変化したらカウントアップ / ダウン（`fx.rollNumber`）。増えたら緑、減ったら赤で一瞬光る
- **トースト・帯・カットイン**: `fx.toast` `fx.band` `fx.cutin`（左右からキャラの絵が滑り込み、文字の **手前** にもキャラの一部が重なる）。MCH の `Style/Cutins/*.css` を参考にしてよい
- **常時の動き（D）**: `js/ui/ambient.js` 新規。全画面の背景に、ランドの色のゆっくりした光の帯・粒子・薄い走査線。`prefers-reduced-motion` と設定の「動きを減らす」で止める。CPU を食わない（canvas 1 枚・30fps 上限・画面外では止める）
- **画面の切り替え**: アプリはホームのアイコンの位置から拡大して開き、閉じるとアイコンに戻る（FLIP、`--t-ui`）。アプリ内のタブは横にスライド
- **効果音**: 既定 OFF のまま。タップ・開く・閉じる・確定・攻撃・陥落に MCH の SE を割り当てる（設定で ON のときだけ）

## 2. ホーム（`js/ui/phone.js`）

- **壁紙**: 選んだランドのクリプタイドの絵を大きく、少しぼかして画面の奥に置く（ゆっくり漂う）。手前に UI、さらに手前にナビゲーター（マインちゃん）の立ち絵が UI の端に少し重なる（B のレイヤー）
- **ナビゲーターの「今日のひとこと」**: 立ち絵＋吹き出し。吹き出しは文字数に合わせて伸び、1 文字ずつ出る（タップで全文）。立ち絵は状況で差分（通常 / 指差し / 喜ぶ / 困る / 驚く）を変える
- **今日のやること（E）**: 吹き出しの下に最大 3 件のカード。優先度順に: 選択待ち（SOUL・エクステンション）→ 食料が足りなくなる見込み（「本拠地で農作」へ直行）→ AP が残っているヒーロー（「Chat で指示」へ直行）→ すべて指示済みなら「ターン終了」
- **資源**: GUM・食料・素材・人口を MCH のアイコンつきで。前日からの増減を小さく（+12 / −5）。食料が 3 日以内に尽きる見込みなら赤く脈打つ
- **アプリのアイコン**: 単色の図形をやめ、角丸の板にグラデーション＋上辺の光＋影。未読バッジは脈打つ。押すと沈む
- **バッテリー**: 残り日数が少ないほど色が変わり、10% 以下で点滅

## 3. MCH Map（`js/ui/map-view.js`）

- **色の優先度（D）**: 地形は彩度を落とし、霧は奥行きのある暗さ（単色の黒ではなく、薄い等高線のような模様）。自ランドの占領地は縁取り。部隊・砦・経路は彩度を上げる
- **部隊**: 待機中はわずかに上下に揺れる。選ぶと足元に光の輪が広がり、カメラがなめらかに寄る（`--t-page`）
- **経路（C）**: 線が出発地から目的地へ伸びる。1 日で届く分と翌日以降の分で線の種類を変える。到着予定日のピン
- **タップ**: タップしたヘックスに波紋。情報シートは下からばねで出る
- **実行フェーズ**: 自分の部隊の動きにカメラが追従。戦闘は攻撃側が少し前に出てから戻る＋ダメージ数字が弾む＋ MCH のバトルエフェクトのスプライト（`Image/Effects/Battle/*.png`）を 1 回再生。砦の陥落はカットイン（攻めたヒーローの絵が文字の手前に）
- **凡例と案内**: 右上の「?」で凡例（地形の色・記号・霧・砦のランク）。初めて開いたときだけナビゲーターが「部隊をタップ → 行き先をタップ」を一度だけ示す（以後は出さない。`mcw.settings` に記録）

## 4. MCH Chat（`js/ui/chat-view.js`）

- **吹き出し**: 文字数に合わせて幅と高さがなめらかに伸びる。ヒーローの返事は 1 文字ずつ（短い「入力中…」の点のあと）。ヒーローの絵は口調ごとに少し違う出方（傾き・跳ね）
- **会話を送るとき（C）**: 新しい吹き出しは下から 500〜700ms でめくれるように入る。古いものは上へ押し出される
- **リッチメニュー**: 各ボタンに **AP の消費** と **できない理由**（AP 不足 / 本拠地にいない / 射程外）を小さく出す。できないボタンは押せるが、押すと理由と **次の一手** のボタンを返す（例: 内政 → 「本拠地へ戻る（経路を引く）」、AP 不足 → 「休息」か「ターン終了」）
- **AP ゲージ**: 残り AP を区切りのあるゲージで。指示を積むと右から減るアニメーション
- **トーク一覧**: ヒーローごとに残り AP のリング・最後のセリフ・状態（敗走 / 指示を仰いでいる）。指示を仰いでいるヒーローは一番上に上がり、脈打つ

## 5. MCH Calendar / Drive / Photo

- **Calendar**: 今日のマスが光る。予定は種類ごとの色のピン。日をタップするとそのマスが開いて詳細が出る（拡大）
- **Drive**: ヒーローのカードは絵を大きく、名前の **裏** に絵が少しはみ出す（B）。パラメーターのバーは開いたときに左から伸びる。レアリティは縁の色と光沢。用語に「?」で説明（統率・知力など 6 つの意味）
- **SOUL の 3 体選択**: 3 枚のカードが裏向きで出て、順にめくれる（600ms ずつ）。選ぶと選んだ 1 枚が前に出て、ほかは下がる
- **Photo**: 写真のグリッドはシャッターのように順に現れる。スワイプ選択はカードを指に追従させ、傾き・影・左右の光（アリ / ナシ）。はらうと勢いのまま飛ぶ。タイマーは円形

## 6. ランド選択・結果

- **ランド選択**: 9 枚のカードは順に浮かび上がる。選ぶとそのカードが画面いっぱいに広がり、ランドの色で画面が染まってからホームへ（最初の「始まり」の演出）
- **結果**: 順位は下から 1 つずつせり上がる。自ランドの行は光る。スコアの内訳は 1 行ずつ数字が転がる。勝ったときはナビゲーターが喜ぶ差分、負けたときは励ます差分

## 7. 分かりやすさ（E）のまとめ

1. ホームの「今日のやること」が、いつも次の一手を 1 つ以上示す
2. できない操作は、理由と次の一手を返す（黙って押せないだけにしない）
3. 初めて開いたアプリでだけ、ナビゲーターが 1 回だけ要点を言う（Map / Chat / Drive / Photo）。「?」でいつでも読み返せる
4. 食料不足は 3 日前から警告し、「本拠地で農作」へ直行できる
5. 用語（AP・統率・砦ポイントなど）は「?」で説明

## 7.5 操作の流れ — 「戻る」「次へ」と、対象 → 指示 → 指示終了（最優先）

プレイテストで分かった、いちばん大きな問題。**ほかの演出より先に、ここを満たす**。

### 7.5.1 戻る・次へ（担当: ホーム班 `phone.js`。各アプリ班は従う）

- **どのアプリにも、上に共通のアプリバー** を置く: 左に **「＜ 戻る」**（文字つき。44px 以上の押せる幅）、中央に画面名、右に「?」。
  戻る先は「1 つ前」（Chat のトーク → トーク一覧 → ホーム、Map のシート → 地図 → ホーム）。端末の下のバーもホームへ戻れるが、それだけに頼らない
- Esc / ブラウザの戻る（`history`）でも同じ「1 つ前」へ戻る
- **判断のボタンは 1 画面に 1 つだけ主役にする**: 次に進むボタン（指示を確定 / 次のヒーローへ / ターン終了 / 選ぶ）は、
  画面の下の同じ場所（親指の届く帯）に、アクセントの金で、文字で行き先を書いて置く（「次のヒーローへ（シートン）」「ターン終了へ」）。
  それ以外のボタンは控えめな色にする。主役が 2 つ並ぶ画面を作らない
- 押せないボタンは灰色だけにせず、理由を 1 行で添える（§4・§7）

### 7.5.2 対象 → 指示 → 指示終了（担当: Chat 班・Map 班。ホーム班は「今日のやること」で入口を出す）

ヒーローごとに **指示のステータス** を持つ（UI の表示だけ。state に保存しない場合は `app.ui` に。エンジンの値から導けるものは導く）:

| ステータス | 条件 | 表示 |
|---|---|---|
| 未指示 | 指示 0 件 かつ AP が残っている | 灰色の丸「未指示」 |
| 指示中 | 指示 1 件以上 かつ AP が残っている | 金の半円「指示中 AP 3/9」 |
| 完了 | プレイヤーが「指示を終える」を押した、または AP 0 | 緑のチェック「完了」 |
| 行動不可 | 敗走中など apMax 0 | 暗い「休み」 |

- **今、誰を選んでいるか** を常に見せる: Chat のトークでも Map でも、画面上部に選択中のヒーローの帯（絵・名前・ステータス・AP ゲージ）を固定で出す。
  Map では選択中の部隊の足元に光の輪を出し、ほかの自分の部隊にはステータスの小さなバッジを付ける
- **ヒーローの並び（ロスター）** を Chat と Map の下（主役ボタンの上）に横一列で出す: 絵の小さな丸 ＋ ステータスの印。
  タップでそのヒーローを選ぶ（Chat ならそのトークへ、Map ならその部隊へカメラが寄る）。今のヒーローは枠が光る
- **「指示を終える」** ボタン: 指示を 1 つ以上積んだら、主役ボタンが「指示を終える → 次のヒーローへ（名前）」になる。
  押すとそのヒーローを「完了」にし、**自動で次の未指示 / 指示中のヒーローへ移る**（トークをめくる / カメラが寄る）。
  AP を使い切ったら押さなくても同じ移動の案内を出す（自動では移らない。0.6 秒後に主役ボタンが光る）
- 全員が完了したら、主役ボタンは **「全員の指示が完了 → ターン終了」** になる。ターン終了はこの流れの終点として 1 か所に集める
  （ホームの「ターン終了」も残すが、未指示のヒーローがいるときは「あと 2 人 未指示」と添える）
- 「完了」にしたヒーローも、ロスターからタップすれば選び直して指示を足せる（取り消しもできる）
- 指示を積んだ瞬間に、積んだ指示の一覧（チップ）が上の帯にアニメーションで加わり、AP ゲージが減る（§4）

### 7.5.3 確かめ方

`tools/smoke.mjs` に、ロスターと「指示を終える → 次のヒーローへ」だけで 3 人全員に指示してターン終了まで行けること、
どの画面からも「戻る」で 1 つ前に戻れることを足す。

## 8. 守ること

- **エンジンは変えない**（見込みの計算が要るなら、エンジンの関数を呼んで UI 側で並べるだけ。新しいルールを UI に書かない）
- **絵文字を使わない**。アイコンは MCH の画像・CSS の図形・文字
- 画像・音声はリポジトリに置かない（`img()`）
- `prefers-reduced-motion` と設定の「動きを減らす」で、常時の動き・カメラの移動・めくりを短くするか止める
- スマホ（390x844）で 60fps を目標。常時の動きは 30fps 上限・canvas 1 枚
- 文書・コード・コミットに、参考にした作品名・人名を書かない（「参考作」と書く）
- `tools/smoke.mjs` が通ること（必要なら追従させる）

## 9. 確かめ方

- `tools/smoke.mjs`（Console エラー 0）
- 画面ごとのスクリーンショットを並べ、上の原則 A〜E ごとに「どこで満たしているか」を一覧にする（レビュー班）
- `prefers-reduced-motion` をエミュレートして、動きが止まり操作は変わらないこと

## 付録: fx の API（基盤班。後の班はこれを使う）

基盤は `css/theme.css`（トークンと共通部品）・`js/ui/fx.js`（手触りの部品）・`js/ui/ambient.js`（常時の背景）・
`js/main.js`（画面の切り替え）。**ルールは書かない**。どの関数も DOM が無い環境（`node --test`）では何もしない。
どの関数も「動きを減らす」（OS の `prefers-reduced-motion` か、設定の「動きを減らす」）のときは、動かさずに結果だけを出す。

```js
import * as fx from './fx.js';          // まとめて: import { fx } from './fx.js' でも同じ
import { toast, band, reducedMotion } from './h.js';   // h.js からも今までどおり取れる（実体は fx.js）
```

### A. トークン（`css/theme.css` の `:root`）

| 種類 | 名前 |
|---|---|
| 背景 3 段 | `--bg-0`（一番奥）`--bg-1`（= 旧 `--bg`）`--bg-2` |
| パネル 3 段 | `--panel-1`（= 旧 `--panel`）`--panel-2` `--panel-3`、線 `--border` `--border-hi` |
| 文字 | `--text` `--text-hi` `--muted` `--muted-2` |
| アクセント金 | `--accent` `--accent-hi` `--accent-lo` `--accent-ink`（金の上の文字） |
| ランド色 | `--garuda` `--ifrit` `--leviathan` `--tiamat`、各ランドは style で `--land` |
| 状態色 | `--ok` `--warn` `--bad` `--info` `--danger` |
| 角丸 | `--r-xs 4` `--r-s 8`（= `--radius-s`）`--r-m 12`（= `--radius`）`--r-l 18` `--r-xl 28` |
| 影 | `--sh-1`（置いてある）`--sh-2`（浮いている）`--sh-3`（ポップアップ）、`--sh-edge`（上辺の光 + 下辺の暗線。`box-shadow: var(--sh-edge), var(--sh-1)` のように重ねる）、`--glow-accent` |
| 質感 | `--noise`（薄いノイズの背景画像。`background: var(--noise) 0 0 / 120px 120px, ...`） |
| 時間 | `--t-tap 120ms`（押した反応）`--t-ui 240ms`（部品の出入り）`--t-flip 380ms`（アプリの開閉）`--t-page 600ms`（めくり・カメラ） |
| イージング | `--ease-out`（減速。ほとんどこれ）`--ease-in`（消える）`--ease-inout` `--ease-spring`（行き過ぎて戻る）、旧 `--ease` |

時間のトークンは「動きを減らす」のとき 1ms になる。CSS の動きは `var(--t-*)` で書けば自動で止まる。
JS で時間が要るときは `fx.token('--t-page', 600)`（ms の数が返る）。

### B. 共通のクラス

| クラス | 見た目 |
|---|---|
| `.panel` | 面の基本。上辺のエッジ光・下辺の暗線・薄いノイズ・影 |
| `.panel--raised` | 一段浮かせる（影が深い） |
| `.panel--glass` | すりガラス（後ろがぼけて透ける。地図の上に重ねる UI など） |
| `.panel--press`（または `button.panel`） | 押せる面。押すと 2px 沈む |
| `.btn-primary` | 金のボタン。数秒に 1 回、光が横切る。押すと縮む |
| `.btn-secondary` `.btn-ghost` `.btn-danger` | 従来どおり（押すと縮む） |
| `.sr-only` | 読み上げにだけ渡す文字 |
| `.toast--good/bad/warn/info` `.band--good/bad/info` | 色違い（fx.toast / fx.band の kind） |

押せるもの（`button`・`[role="button"]`・`a[href]`・`.panel--press`・`[data-ripple]`）は、**何もしなくても押した場所から波紋が出る**
（`fx.install()` を main.js が起動時に 1 度呼ぶ）。金の波紋にしたいときは `data-ripple="accent"`、出したくない所は `data-ripple="off"`。
音が ON のときは押すとタップの SE（`.btn-primary` は確定の SE）も鳴る。

### C. 関数

| 関数 | 使い方 |
|---|---|
| `fx.ripple(el, clientX?, clientY?, {accent?})` | 波紋を手で出す（キーボードで決めたときなど）。要素の中には何も足さない（fixed の箱を重ねる） |
| `fx.rollNumber(el, to, {key?, from?, ms?, format?, flash?})` | 数を転がして表示。増えたら緑・減ったら赤で一瞬光る。**描き直しで要素が作り直されるので `key`（例 `'res.gum'`）を渡す**と前回の値から転がる。初回（前の値が無い）はそのまま出す。`format: (n) => Math.round(n).toLocaleString()` |
| `fx.toast(text, {kind?, icon?, key?, ms?})` | 右上のトースト（端末の中）。`icon` は MCH の相対パス（`'Image/Icons/gum.png'`）。同じ `key` が続くと文を差し替えて弾む。残り時間の細い線つき |
| `fx.band(text, {kind?, sub?, ms?})` | 画面中央の帯。2 行目に `sub`。`band(text, 1200)` の古い書き方も可 |

### D. 常時の背景（`js/ui/ambient.js`）

端末の一番奥に canvas を 1 枚。ランドの色の光だまり・斜めの光の帯・浮かぶ粒子・薄いヘックスの格子・走査線。
30fps 上限、タブが隠れた・画面外・地図（全面を自前で塗るアプリ）では止まる。動きを減らすときは 1 枚だけ描いて止まる。

- main.js が描くたびに `ambient.setScene({ app, color })` を呼ぶ（色は自ランドの色）
- **背景を見せたい画面は、画面の一番外側の要素に不透明な背景を塗らない**（ホームは透明。`.chat--talk` のように `var(--bg)` を塗ると隠れる）
- `ambient.pulse(color?)` で一瞬明るくできる（ランドを選んだ・ターンが明けた など）

### E. 画面の切り替え（main.js の `render()`）

アプリが変わったときだけ動く。各班は何もしなくてよい。

- ホーム → アプリ: そのアプリのアイコンの位置から広がって開く（奥のホームは沈んで消える）
- アプリ → ホーム: 消える画面がそのアプリのアイコンへ縮んで戻り、アイコンが弾む
- そのほか: 直前に押したもの（ボタン・カード）の位置から広がる。押したものが無ければ横にすべって入る
- 消える画面は `.phone__ghost`（押せない写し）として切り替えの間だけ残る。新しい画面は寸法・位置を変えない
- 開く / 閉じるの SE（音が ON のとき）。ポップアップも、ばねで出て沈んで消える（閉じた瞬間に `.popup` ではなくなる）

### F. 効果音（`js/ui/audio.js` の `playSe(name)`。既定 OFF）

`tap`（押した）・`open`（アプリを開く）・`close`（閉じる）・`confirm`（主要ボタン）・`attack`（攻撃）・`fall`（陥落）。
以前からの `hit` `build` `fort` `win` `lose` もそのまま。同じ SE は 250ms 以内に重ねない。
