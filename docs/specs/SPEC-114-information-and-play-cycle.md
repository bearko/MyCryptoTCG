# SPEC-114 — 情報の見せ方と 1 日の流れ

プレイテストの不満「いま何が起きているか、兵はどれだけいて、GUM や食料の収支はどのくらいで、敵国との戦力差がどのくらいか、
情報が足りない」に応える。国家運営系の参考作を調べ、共通する原則を MyCryptoWars の形に落とした
（調査の詳細は非公開の報告。ここでは作品名を書かない）。

**数字はすべてエンジンの関数から取る**（SPEC-113 §6.3 の `breakdown` / `forecast` / `previewDomestic` / `previewRation` / `battle.predict`）。
UI で計算し直さない。UI の決まりは SPEC-111・112 のまま（戻る・主役ボタンは 1 つ・動きを減らす設定・絵文字なし）。

## 0. 参考作から採った原則

| # | 原則 | ここでの形 |
|---|---|---|
| 1 | 残高の横に、毎ターンの増減を必ず添える | 資源は「食料 41（−15/日）」。前日差ではなく今日の見込み |
| 2 | 危ない資源は「あと何ターンもつか」で言う | 赤字の資源にだけ「あと N 日」。黄と赤の 2 段 |
| 3 | 内訳は 1 タップで開き、足すと合計になる | 資源をタップ → 内訳シート。兵の消費は部隊ごとの行 |
| 4 | 押す前に結果の見込みを見せる | 内政・配給・攻撃のボタンに「押すとこうなる」 |
| 5 | 罰は段階で、前もって知らせる | 食料と士気の警告を前日に出す。罰が起きたら誰に何が起きたか書く |
| 6 | ターン終了がやり残しを教える | 主役ボタンに「食料が今夜尽きる」の段を足す（止めるのは 1 回だけ） |
| 7 | 通知は束ねて、重大なものだけ目立たせる | 朝の報告 1 枚にまとめ、赤い行を先頭に |
| 8 | 他国とは順位と差で比べる。霧の中はぼかす | 順位表と「あなたの何倍」。視界外は「?」 |
| 9 | 攻撃の前に見込みを、幅と言葉で出す | 「自 320 → 210〜240 ／ 敵 180 → 0〜40 ・ 優勢」 |
| 10 | 最初から全部出さない | 順位表と隣国の脅威は、初めて敵ランドを見つけた日に開く |
| 11 | 助言は効き目つきで。効かない手は勧めない | マイちゃんの「今日のやること」に効き目を添える |

## 1. 1 日の流れ（毎日通るのはホームと Chat の 2 画面）

| 段 | 画面 | 見せる | 判断 | 前 → 後の気持ち |
|---|---|---|---|---|
| 朝の報告 | ホーム上段 | きのうの差分（最大 5 行。赤い行が先） | 今日まず見るところ | 何が起きた? → 原因が分かって納得 |
| 把握 | ホーム | 資源・兵・士気・脅威・砦 pt | 立て直す日か、攻める日か | 全体が見えない → 危機がはっきりする |
| 原因 | 内訳シート（赤のときだけ） | 収入と支出の行 | 兵を減らす・産出を増やす・配給を変える | なぜ足りない? → 自分で気づく |
| 内政 | Chat | 各ボタンの見込み、積んだ指示のあとの収支 | どの内政か | 何が効くか分からない → 試して決められる |
| 軍事 | Map（攻める日だけ） | 攻撃の見込み、遠征後の食料 | 攻めるか待つか | 怖い → 自分で選んだリスク |
| 締め | 主役ボタン | 1 行の要約とやり残し | このまま進めるか | やり忘れの不安 → 踏ん切り |
| 週報 | 日曜の夜（7・14・21 日目） | 順位表と先週との差 | 次の 1 週の方針 | 位置が分からない → 目標が立つ |

## 2. ホーム

### 2.1 朝の報告（最上段・畳める）

- 実行フェーズのあと、ホームの最上段に **朝の報告** のカード（ロック画面の通知のように重ねた形）。最大 5 行、重大なものから:
  飢え・逃走（赤）→ 自国の戦闘・占領された（赤）→ 士気の大きな変化（黄）→ 資源の差し引き（灰）→ 他国の動き（灰）
- 各行に理由を 1 語添える（「兵 −51（逃走）」「食料 −15（産出 +9・消費 −24）」）。行をタップすると関係する画面へ（内訳・地図のマス・トーク）
- 残りは「ほか N 件」。開くと全部。カードは右上の × で畳め、次の朝まで出ない
- データは実行フェーズのイベント（`state.log`）とエンジンの `forecast` から作る

### 2.2 資源のウィジェット

- 4 資源（GUM・食料・素材・人口）を **「残高｜±N/日」** の 2 段で。マイナスは赤、プラスは緑、0 は「±0」（色だけに頼らず符号を必ず書く）
- 赤字の資源には **「あと N 日」** のチップ。**黄 = 5 日以下、赤 = 2 日以下か今夜尽きる**。28 日目より後に尽きるなら出さない
- 5 つ目のウィジェットに **兵**: 「兵 1,043（上限 2,310）」と **士気の平均**（ゲージ。20 未満は「動揺」、0 の部隊がいれば「逃走中」の赤）
- タップで **内訳シート**（§3）

### 2.3 状況の 1 行（初めて敵ランドを見つけた日から）

- 「砦 12pt（3 位・1 位まで −3）・日曜の集計まで 2 日」
- 「いちばん近い脅威：ルビー 兵 〜420（あなたの 0.75 倍）」。視界外の値は最後に見た日つき（「3 日前」）か「?」

### 2.4 今日のやること（SPEC-112 のものを直す）

- 勧める手に **効き目** を添える（「本拠地で農作 ×3：食料 あと 1 日 → あと 4 日」）。足りない手しか無いなら、配給「節約」・恩賞・休息を先に出す
- 士気 20 未満の部隊がいれば「恩賞で士気を上げる（GUM 25）」「本拠地で休息」を出す

## 3. 内訳シート（下から出る。ホームの資源・兵のウィジェットから）

- タブ: 食料 / GUM / 素材 / 人口 / 兵と士気
- 各資源: 収入の行（地形・農地・街の隣接・内政）と支出の行（人口・**部隊ごとの兵**）、差し引き、残高、上限、あと N 日。
  行の合計は必ず差し引きに一致する（`breakdown` の値をそのまま出す）。0 の行は隠す
- 食料のタブに **配給の切り替え**（節約 / 通常 / 増量）。選ぶ前に `previewRation` で「食料 −15 → −6/日・士気 毎日 −4」を出す
- 兵と士気のタブ: 部隊ごとに 兵 / 上限・食費 −N/日・士気（ゲージと数字）・いる場所・今日の指示。士気 0 の部隊は「逃走中 −8%/日」
- 行をタップすると、その行を動かす操作へ（部隊 → そのトーク、農地 → Map のそのマス）

## 4. Chat（指示の画面）

- **内政のボタンに見込み**（`previewDomestic`）: 「農作 食料 +44（あと 3 回）」「徴兵 兵 +30・食料 −6/日（ずっと）」「商業 GUM +40」「工作 素材 +23」「恩賞 GUM −25・士気 +20」
- 内政のサブメニューは **押しても閉じない**（続けて積める）。積んだ回数を「×3」で出す
- 積んだ指示の帯に **「このあと：食料 −15 → +29/日」**（積んだ内政の `perDay` を足す）
- トークの上の帯（選択中のヒーロー）に **士気**（ゲージ）と **食費 −N/日** を足す
- 指示の取り消しに **「1 手戻す」** を足す（最後の指示だけ外す。AP も戻る）。いまの「すべて取り消す」も残す

## 5. Map（攻める日）

- 敵の部隊・砦・本拠地をタップしたシートに **攻撃の見込み**（`battle.predict`）:
  「自 320 → 210〜240 ／ 敵 180 → 0〜40」とラベル（圧倒 / 優勢 / 互角 / 劣勢 / 絶望的）、含まないもの 1 行（「回避とスキルの運で上下します」）
- 実行フェーズの戦闘の結果に **「予想 −60〜−90 → 実際 −75」** を並べる（予想は指示したときの値を `app.ui` に控える）
- 部隊のバッジに士気の色（20 未満は黄、0 は赤）
- 隣接する敵ランドの部隊のバッジに **「×1.4」**（相手の兵 ÷ 自分の総兵力）。視界外は出さない

## 6. Drive

- ランドのタブを **順位表** に: 順位・ランド・砦 pt・兵・占領マス。初期表示は「砦 pt」と「兵」の 2 列、ほかはタブで切り替え。自分の行を強調。
  値は **朝の時点で固定**（ターンの途中で探って数字を当てられないように）。視界に一度も入っていないランドの兵は「?」
- 日曜の夜（7・14・21 日目の実行のあと）は、ホームの朝の報告の先頭に **週報**（順位の上下を矢印で、先週との差を ±）

## 7. 主役ボタン（SPEC-112 §7.5 の続き）

- 全員の指示が済んだあとの主役ボタンの上に 1 行: 「食料 +29/日・士気 平均 58・未指示 0 人」
- 食料が今夜尽きる見込みなら、主役ボタンは **「食料が今夜尽きます（士気 −15）→ それでも進める」**。1 回目は内訳シートを開くだけ、2 回目で進む

## 8. 用語と表記

- 「士気」「配給」「恩賞」「逃走」を `data/messages.json` の `ui` と用語の「?」に足す
- 増減の表記は「+N / −N / ±0」（マイナス記号は U+2212 ではなく通常のハイフンでもよいが、画面の中で揃える）
- 色だけで意味を伝えない（符号・言葉・アイコンを添える）

## 9. 確かめ方

- `tools/smoke.mjs` に: 朝の報告が出る / 資源のウィジェットに「/日」と（赤字なら）「あと N 日」/ 内訳シートの行の合計が差し引きと一致 /
  内政のボタンに見込みが出て、押しても閉じず続けて積める / 「1 手戻す」で AP が戻る / 配給を切り替えると見込みが変わる /
  敵をタップすると攻撃の見込みが出る / 順位表が出る、を足す
- 画面ごとのスクリーンショットを、上の原則 1〜11 ごとに「どこで満たしているか」で点検する
