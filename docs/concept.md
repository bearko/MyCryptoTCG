# MyCryptoWars — 原案（企画構想）

MVP の仕様は `docs/spec.md`。ここは、作り直しの元になった構想をそのまま残したもの。

## コンセプト
- 歴史戦略 SLG や文明育成ゲーム（参考作）のようなシミュレーションゲーム
- 初期マイクリの「士農工商」の考え方や懐かしのランド対抗イベントの他、「ランドシステム」などのマイクリ色の強い機能を盛り込みたい

## ゲームの目的
- 周りのプレイヤーと協力/競いながら9つあるランドの内、自国を最強のランドにすること（1ヶ月ワンサイクル）

## ゲームの基本的な流れ
- 各プレイヤーは9つのランドの内、一つを選んでスタート
- 内政で徴兵や農作、商業、工作をして自国を育てる
- 周辺のマップを探索しながら新しい資源や協業国を見つけていく
- エネミーがいる拠点は敵対国なので殲滅する必要あり
- 各エリアに関所（砦）があり、それをいかに攻略して次のエリアに進むかが鍵。他のランドより早く関所を落とせるかが最初の関門
- 関所はRare砦、Epic砦、Legendary砦の3種類があり、一定期間ごとに砦を占拠するランドに得点が入る
- 4週間のシーズン終了に最も砦ポイントが多いランドが優勝

## ステージ
- 文明育成ゲーム（参考作）のようなハニカム構造
- パネルは土地パネル、施設パネル、拠点パネルの3種類

### 土地パネル
現実世界の地形をベースとしたパネル。マップは全て土地パネルで構成される。土地パネルの上に施設パネルと拠点パネルが乗る。
南北緯度により地形の分布が大まかに決まっており、陸と海の割合、陸の大きさや種類も地球をベースに構築。形だけオリジナル。

土地による効果
1. 行動範囲にバフ/デバフ（例：山岳地帯は移動範囲にマイナス）
2. 資源が手に入る（占領した土地から定期的に。種類と量は地形で違う）
3. 施設/拠点を建築できる（コストを払う。山岳など建築できないパネルもある）

```
【平地系】
- 土：効果なし
- 草原：南北緯20°から70°。歩兵は移動速度デバフ、騎兵はバフ
- 砂漠：南北緯20°から50°。移動速度デバフ。夏季は体力が徐々に減少
- 砂浜：海沿い。移動速度デバフ
- 沼地：移動速度デバフ。体力が徐々に減少（微減）
- 氷原：南北緯45°以上。冬季は体力が徐々に減少
【高地系】
- 山岳：原則進入不可。一部ヒーローのみ通行可能
- 火山：原則進入不可。一部ヒーローのみ。稀に噴火し周辺に大ダメージ
- 崖：進入不可
【河川、海系】
- 河川：移動速度大幅デバフ。冬季は体力が徐々に減少
- 大河：原則進入不可。橋か船
- 湖：船での移動が必要
- 浅海：船での移動が必要
- 深海：一定以上のレベルの船
```

## 資源
- ヒーロー：戦闘やら内政やらを指示する先
- エクステンション：戦闘や内政に有用な効果を持つアイテム
- 人口：内政なら生産力、戦闘なら戦闘力の指標
- 素材：エクステンションを開発するための素材
- 食料：内政では国庫、戦闘では兵站
- 金銭：何かにつけて必要

## 施設パネル
- 街：人口と金銭。隣接する他の施設に上方補正。河川か海にしか隣接できない
- 農地：食料。元の地形で収穫量が変わる
- 採掘場：素材。ランクで採掘範囲・種類が増える。元の地形で採掘できる素材が変わる
- 工房：素材と金銭でエクステンションをクラフト
- 市場：素材やエクステンションで金銭を稼ぐ／買う
- 宿舎：人口のキャパ
- 食料庫：食料のキャパ
- 銀行：金銭を賊軍から守る
- 倉庫：素材のキャパ

## ヒーロー
- 歴史戦略 SLG（参考作）の「武将」相当。どのヒーローも戦闘も内政もできる（得意不得意はある）
- マイクリの元のパラメーターから変換。小数点以下は切り上げ
  - 行動力 `3 + AGI / 15`
  - 統率力 `(HP / 4 + PHY + INT + AGI) / 5`
  - 武力 `(PHY + INT) / 14`
  - 知力 `INT × 0.55`
  - 統治力 `(INT + AGI) / 6`
  - 政治力 `(PHY + AGI) / 6`
- スキルは Attribute と史実で得意領域を判定
- 行動力：あらゆる行動で消費。0 になったらそのターンの行動は終了。繰り越さない

## フィールド
- マップは大きな球体。スタート地点に 9 つのランドが密集、裏側に Legendary 砦
- 最初のスポーン地点が 9 つの国の領土、それ以外はエネミーが占領しているエリア

## ヒーローの獲得
- エネミーの砦を攻略すると SOUL。SOUL でランダム 3 体から 1 体を選ぶ。SOUL は得意領域 × レアリティ（上振れあり）
- 他ランドの砦を落とすと相手のヒーローを仲間にできる場合がある（忠誠度）
- 他ランドの本拠地を征服すると捕まえたヒーローは仲間

## ゲームサイクル
【行動指示フェーズ】⇔【実行フェーズ】の繰り返し（文明育成ゲーム（参考作）の形）
- ターン制。全プレイヤーが指示し、実行フェーズで自動的に行動
- 実行フェーズ中は 1 秒で 1 ヶ月のペースで時間が進む。指示フェーズでは進まない
- マルチプレイ対応時はリアルタイム進行、順次行動にしたい

### 計画指示フェーズ
- 行動力に応じて「移動」「戦闘」「開拓」「内政」（内政は拠点パネルにいるときだけ）
- 移動：1 パネル 1 消費。地形のバフ/デバフ
- 開拓：開拓可能な地形で、コストを払う。余った行動力で工数を短縮
- 戦闘：拠点侵攻/防衛（攻撃範囲に拠点があればどこからでも）と、行軍中の戦闘
  - 侵攻ではスキルの自動/手動発動を選べる（既定は手動）
  - 防衛では迎撃優先/防衛優先
  - 実行フェーズ中に指示できるのは、攻撃対象・撤退/退却・スキル発動・自動/手動の切替だけ

### 行軍中の戦闘
- 接敵時の方針：無視／戦闘／指示を仰ぐ
- 攻撃を受けたら 回避判定 → 防御判定 → ダメージ判定
- 反撃：戦闘を選んでいた場合。射程外なら射程内まで移動。行動力が 0 になったら終了
- 奇襲：視界外からの攻撃。回避なし。奇襲されると行動力と士気が大幅に下がる

## 部隊の種類
- 前衛：先鋒（行動力高い）／攻撃（行動力低く攻撃高い）／重装（行動力低く防御高い）／指揮（バフ）／偵察（行動力高く戦闘力低い）
- 中衛：狙撃（範囲狭く頻度高い）／術・支援（バフ/デバフ/回復）
- 後衛：射撃（範囲広く頻度低い）／術・攻撃（特殊攻撃）／回復

## データ
- ヒーローそれぞれに固有のセリフ。メッセージ ID でテーブル管理

## 「UIで遊ぶ」ゲームにしたい
- UI の気持ちよさを追求。世の中の UI がイケてるアプリの操作感を織り交ぜる
- マッチングアプリ風に左右にフリックしながら報酬のエクステを選ぶ（制限時間内に「アリ」を選ぶ。終了後に候補が複数ならランダム。選ばなかったら残りからランダム）
- 「めっちゃ便利なスマホを持って英雄たちが集う異世界に転生した」
  - MCH Chat：武将とのコミュニケーションと指示（メッセージアプリ風。公式アカウントのリッチメニュー。選択式。武将によってテンションが変わる）
  - MCH Calendar：侵攻予定・完成予定
  - MCH Map：マップ。検索・経路策定・連絡（宣戦布告・外交）。経路策定から実行で武将を向かわせる
  - MCH Photo：所有エクステ（写真に撮って解析している感じ。廃棄は写真の削除）
  - MCH Drive：武将/エネミーのデータベース

## 世界観
プレイヤーはすごいスマホを活用して、マイクリのヒーローをまとめ上げ、エネミー拠点を攻略する（Legendary 砦攻略でクリア）

## ゲームオーバー
- 武将の全滅／本拠地の陥落／ギブアップ／タイムアップ（バッテリー切れ）
- ローグライク（参考作）のようにスコアが出て、スコアに応じたトークン。トークンでマインちゃんにアプリのバージョンアップを依頼（コストはトークンの価格と連動）
- 裏ボスは転生の仕組みを作っている神々（姉妹作）。表ボス撃破時の構成でそのまま挑む
