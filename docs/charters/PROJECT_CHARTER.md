## 1. プロジェクトの目的

**MyCryptoTCG (= MCT)** は、 MyCryptoHeroes (= MCH) 経済圏のヒーローで戦う、
**64×64 ピクセルアニメ × 高速カードバトル** のトレーディングカードゲーム。

任天堂 「高速カードバトル カードヒーロー」 (DS, 2007) のターン構造とリソース
管理 (= ストーン) をコアルールベースに採用し、 MCH の世界観 (= ヒーロー /
エクステンション / スキル / GUM / CE) を上乗せする。 プレイヤーは MCH ヒーロー
を召喚し、 ストーンでとくぎを発動して、 相手マスターの HP を 0 にすれば勝利。

ターゲット体験は **「1 バトル 5〜10 ターンで決着 / モバイルで片手 portrait
プレイ可」**。 演出は MCH のカラーパレット (= 黒地 + 強調色) + ピクセルアートの
ハイブリッドで、 シネマティックな攻撃エフェクトを志向する。

## 2. スコープ (= 何を作るか)

### In Scope (= 作るもの)

- **カードバトル**: 1v1 デモバトル (= 固定デッキ vs CPU)、 高速ターン制
- **MCH ヒーロー召喚**: 手札からストーン消費で場に配置、 召喚酔い 1 ターン
- **とくぎ / 攻撃**: ストーンを消費してヒーローのスキル発動 / 通常攻撃
- **スプライトアニメ**: idle / attack / hit の 3 状態を CSS `steps()` + 64×64 sprite sheet で
- **マスター HP**: ストーン数で表現、 0 で敗北
- **デッキ切れ判定**: ドロー不能で敗北
- **JP / EN 切替**: i18n キーベースの動的切替
- **ランキング (= UI スタブ)**: Day 1 では送信 UI のみ、 backend B (= Upstash + Vercel) の正式実装は SPEC-013 で
- **MCH 経済圏遵守**: ヒーロー名 / スキル名 / エクステンション名は MCH 公式 DB から引用

### Out of Scope (= 作らないもの / Phase 2 以降)

- **レベルアップ**: Day 1 は Lv1 固定 (= SPEC-008 で実装)
- **エクステンション装備**: MCH の装備カード戦闘内効果 (= SPEC-009)
- **デッキビルダー**: カード一覧 + 編成 UI (= SPEC-010)
- **パック開封**: GUM でパック購入 → カード入手 (= SPEC-011)
- **コレクション**: 所持カード一覧 (= SPEC-012)
- **セーブ / ロード**: localStorage 永続化 (= Phase 2)
- **PvP / マルチプレイヤー**: 対人通信戦 (= 範囲外、 採用しない予定)
- **時間進行 (= tick)**: テンプレ機能だが MCT では非採用 (= バトル中心、 ホーム待機概念なし)

## 3. 成功基準

- **動作**: `index.html` をブラウザで開いて Console エラー 0、 1 バトル完走
- **テンポ**: 1 バトル 5〜10 ターンで決着 (= 平均 90 秒以内、 中央値ターゲット)
- **演出**: 主要ヒーロー 3 体以上で idle + attack + hit のアニメが視認できる
- **互換性**: PC (1280×800) + Mobile (375×667) で UI 破綻なし
- **i18n**: JP / EN 切替で全画面のテキストが翻訳される (= 翻訳漏れ警告 0)
- **MCH 整合**: ヒーロー / エクステンション / スキル の **全名称が MCH 公式と一致**
- **ランキング送信エラー**: 正式実装後、 1% 以下 (= SPEC-013 の DoD)

## 4. 制約

- **技術スタック**: プレーン ES Modules + バニラ JS、 TypeScript / バンドラ / フレームワーク **なし**
- **ホスティング**: 静的 host (= Vercel) 前提、 `build:` ステップ不要
- **データ取得**: `data/*.json` から runtime fetch、 ハードコード禁止
- **アセット URL**: `js/constants.js` の `ASSET_BASE` 経由ですべて解決
  - スプライト = 自リポ `assets/sprites/heroes/<heroId>/<action>.png`
  - 静止アイコン (= GUM / CE / ヒーローポートレート) = MCH 公式 CDN 併用
- **localStorage prefix**: `mctcg`
- **多言語**: ja / en の 2 言語 (= デフォルト ja、 ブラウザ言語で自動検出)
- **ターゲット**: PC ブラウザ + モバイル (= iOS Safari / Chrome Android)
- **MCH 経済圏遵守**: `CLAUDE.md` 「MCH 経済圏の遵守」 セクションに従う
  - 名称: ヒーロー / エクステンション / スキル / GUM / CE / エネミー (= 独自呼称禁止)
  - アイコン: MCH 公式
  - 名称ソース: `https://github.com/bearko/mycryptoheroes`

## 5. 主要なペルソナ

### ペルソナ A — 「MCH 既存プレイヤー」

- 30〜40 代、 NFT 黎明期から MCH に触れている
- ヒーロー名 / エクステンション名を見ただけで愛着が湧く
- 「自分の MCH ヒーローが pixel art で動く」 ことに価値を感じる
- 1 バトル数分以内で気軽にプレイできる時間軸を求める

### ペルソナ B — 「カードヒーロー DS 経験者」

- 30〜40 代、 任天堂のカードヒーロー (= DS 高速版) を遊んだ世代
- 「ストーン補充 + 召喚酔い + マスター HP」 のリソース管理に懐かしさを感じる
- 高速テンポと戦略性のバランスを評価する

### ペルソナ C — 「pixel art / レトロゲーム愛好家」

- 年齢層幅広い
- 64×64 pixel art のクオリティとアニメーションの気持ちよさで遊ぶ
- 演出 (= 斬撃エフェクト / マスター shake / 数値 float) で気分が上がる
