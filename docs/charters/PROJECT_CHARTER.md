## 1. プロジェクトの目的

**MyCryptoWars (= MCW)** は、 MyCryptoHeroes (= MCH) 経済圏のヒーロー・ランド・エネミーで遊ぶ、
**ヘックスマップのターン制シミュレーション**。 歴史戦略 SLG・文明育成ゲーム（参考作）の
「内政 → 探索 → 関所の攻略」 のサイクルに、 MCH の 「9 つのランド」 「士農工商」 「SOUL と
エクステンション」 を上乗せする。

世界観は **「めっちゃ便利なスマホを持って、英雄たちが集う異世界に転生した」**。
画面はスマホ 1 台で、 プレイヤーはアプリ（MCH Map / Chat / Calendar / Drive / Photo）を
操作してヒーローに指示を出す。 **「UI で遊ぶ」** ゲームにする（原案 `docs/concept.md`）。

ターゲット体験は **「1 シーズン（28 ターン）を 20〜40 分で遊び切り、 砦ポイントで 9 ランドの
頂点を競う」**。

## 2. スコープ (= 何を作るか)

### In Scope (= MVP。 SPEC-109 §12)

- **9 ランド**: プレイヤー 1 + CPU 8。 MCH のランド名・ランドセクタ・クリプタイドの絵
- **ヘックスの世界生成**: 緯度帯で地形、 東西ループ、 霧（未探索）
- **資源 4 種**: 人口 / 食料 / GUM / 素材（素材は 1 種類）
- **施設 6 種・ランク 3**: 街 / 農地 / 採掘場 / 宿舎 / 食料庫 / 倉庫
- **ヒーロー**: MCH の HP/PHY/INT/AGI から 6 パラメーター、 10 種の部隊、 MCH のパッシブスキル名
- **コマンド**: 移動 / 占領 / 開拓 / 戦闘 / 内政 / 休息 / 方針
- **戦闘**: 回避 → 防御 → ダメージ、 奇襲、 反撃、 砦の守備方針
- **砦**: Rare 6 / Epic 3 / Legendary 1。 週末に砦ポイント。 Legendary 攻略でクリア
- **SOUL**: 砦の攻略で 3 体から 1 体。 **エクステンション**: マッチングアプリ風のスワイプで選ぶ
- **スマホ UI**: ホーム + 5 アプリ、 バッテリー（残り日数）、 実行フェーズの演出
- **スコアとセーブ**（localStorage）

### Out of Scope (= MVP の外。 原案にはある)

- マルチプレイ・リアルタイム進行
- 本当の球体・船・橋・火山の噴火
- 素材の種類分け・工房・市場・銀行・賊軍
- 外交・宣戦布告・撤退の指示・忠誠度・他ランドのヒーローの引き抜き
- トークンによるアプリのバージョンアップ・裏ボス（姉妹作のキャラクター）
- ランキング・bearko.games 共通基盤への送信（SDK は読むだけ）
- 英語 UI（i18n 基盤は残すが、 MVP は日本語のみ。 英語は別 SPEC）

## 3. 成功基準

- **動作**: `index.html` を静的サーバーで開いて Console エラー 0、 1 シーズン完走
- **テンポ**: 1 ターンの指示が 1〜2 分、 実行フェーズの演出が 10 秒以内（スキップ可）
- **CPU**: 28 日のうちに CPU ランドが Rare 砦を落とし、 誰かが Legendary に届くシードがある
- **互換性**: PC (1280x800) + Mobile (375x667) で UI 破綻なし。 スマホの縦画面が基準
- **MCH 整合**: ヒーロー / エクステンション / スキル / ランド の **全名称が MCH 公式と一致**
- **テスト**: `node --test tests/*.test.mjs` が通る。 `node tools/sim.mjs` で 28 日の無人シミュレーションが落ちない

## 4. 制約

- **技術スタック**: プレーン ES Modules + バニラ JS、 TypeScript / バンドラ / フレームワーク **なし**。 `package.json` を置かない
- **ホスティング**: 静的 host 前提、 `build:` ステップ不要
- **データ取得**: `data/*.json` から runtime fetch、 ハードコード禁止
- **アセット URL**: `js/constants.js` の `ASSET_BASE` (= `https://raw.githubusercontent.com/bearko/mycryptoheroes/main/`) 経由ですべて解決。 **画像・音声をこのリポジトリにコミットしない**
- **localStorage prefix**: `mcw`
- **エンジンは純粋関数**: `js/engine/*` は DOM に触れない。 乱数はシード付き（再現できる）
- **固有名詞**: 実在のゲーム名・製品名は書かない（「参考作」 と書く）。 人の実名を書かない
- **MCH 経済圏遵守**: `CLAUDE.md` 「MCH 経済圏の遵守」 に従う
  - 名称: ヒーロー / エクステンション / エネミー / GUM（通貨は GUM と呼ぶ。 「金銭」 「ゴールド」 と書かない）
  - 「ユニット」 と書かない。 ヒーローが率いる兵は **部隊**（コードでは `squad`）
- **絵文字を使わない**（UI / 文書 / コミット）

## 5. 主要なペルソナ

### ペルソナ A — 「MCH 既存プレイヤー」

- 30〜40 代。 ランドに所属していた記憶があり、 9 ランドの対抗戦に懐かしさを感じる
- 自分のランドの色のヘックスが広がっていくことに愛着が湧く

### ペルソナ B — 「歴史戦略 SLG・文明育成ゲーム経験者」

- 内政と探索と関所攻略のサイクル、 武将のパラメーター変換に興味がある
- 1 シーズン 30 分で遊び切れるテンポを評価する

### ペルソナ C — 「UI で遊ぶ人」

- 地図アプリの経路、 メッセージアプリの選択式の指示、 マッチングアプリのスワイプといった
  手触りを、 ゲームの中で使えることに面白さを感じる
